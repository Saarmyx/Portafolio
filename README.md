# Santiago Sarmiento · Portfolio

Portfolio personal desarrollado con React para presentar mis proyectos, stack tecnológico y enfoque como desarrollador Fullstack.

Diseñado con una estética minimalista, arquitectura modular y experiencia fluida tanto en desktop como mobile.

---

## 🌐 Demo

🔗 https://portafolio-saarmyx.netlify.app/

---

## 📌 Objetivo

Este proyecto funciona como presentación profesional y espacio experimental para explorar:

- Arquitectura frontend moderna
- Componentes reutilizables
- Diseño minimalista
- Animaciones suaves
- Experiencia de usuario
- Organización escalable de proyectos React

El enfoque principal fue construir una interfaz limpia, rápida y técnicamente sólida.

Porque un portfolio también refleja cómo piensa el desarrollador. Bastante inconveniente para quienes copian templates de Figma y rezan por empleo.

La aplicación está dividida por secciones independientes para mantener:

- modularidad

Cada sección contiene:

- componente principal
- subcomponentes
- estilos encapsulados

## 🚀 Instalación local

Clona el proyecto:

```bash
git clone https://github.com/Saarmyx/portfolio.git
```

Instala dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Build de producción:

```bash
npm run build
```
